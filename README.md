# Pulse

Интерфейс мобильного приложения для мониторинга API и сервисов (Flutter, без сторонних пакетов).

Экраны: вход, регистрация, обзор, список сервисов, настройки, новый сервис. Данные демонстрационные.

## Сборка APK через GitHub

1. Создайте на GitHub новый репозиторий с любым свободным именем.
2. Загрузите в него всё содержимое этой папки: lib, pubspec.yaml, README.md и скрытую папку .github.
3. Откройте вкладку Actions, выберите слева Build APK и нажмите Run workflow.
4. После зелёной галочки откройте запуск и скачайте pulse-apk из раздела Artifacts. Внутри лежит app-release.apk.

Сборка запускается при загрузке файлов в любую ветку, имя ветки менять не нужно.

## Сборка APK на своём компьютере

1. Выполните: flutter create pulse_app
2. В созданном проекте замените папку lib и файл pubspec.yaml на те, что лежат здесь. Папку test можно удалить.
3. В папке проекта выполните: flutter build apk --release
4. Готовый файл: build/app/outputs/flutter-apk/app-release.apk
